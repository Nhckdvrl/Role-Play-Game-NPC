## 背景

上一个子题 [persona-consistency](../../projects/persona-consistency/SUMMARY.md) 于 2026-11-02 归档。根本原因是：整个项目使用的 LLM 裁判（Qwen3-32B 非思考模式）未经人工验证，会把角色坚定的语气当作“纠正”，漏掉了绝大多数应被判为失败的回复。由此产生的讨论原则：

1. 任何裁判或奖励模型在使用前，都必须先用人工标注验证；
2. 优先选择有结构化真值、或能做到不依赖裁判的测量；
3. **不赌假设**（用户 2026-11-02 明确提出）：研究计划应建立在已确立的事实上，每个关键环节都应有独立的先验证据。论文的核心贡献，不应押在某一个尚未证实的现象上；
4. 只做纯分析、不给出新方法（训练或训练无关），投稿前景有限（用户 2026-11-02 提出）。

## 当前状态（2026-11-02，第 10 轮后，含可行性实验）

- 用户认为 Z1（角色认知）拥挤，改为考察 V“角色的声音”。
- **小规模可行性实验已完成**（4 个模型，Friends 1,800 句 + Cornell 2,044 句，不依赖裁判），结果与预期相反：
  - Friends 中，三个指令模型生成的角色**比原剧本更好区分**：10 句一组时 Gemma 0.94、Llama 0.84、Qwen3-8B 0.58，原剧本 0.36；
  - Gemma 甚至比原台词更“像”原角色（忠实度 0.59 对 0.46），口头禅被大量重复，还被安到别的角色身上，属于脸谱化；
  - 基座模型的可分性与原剧本相当；
  - 冷门的 Cornell 角色上，所有模型都不如原台词像。
- **测量灵敏度对这个效应足够**；核心问题可以改写为“声音校准”：不压平，也不夸大。
- 必须补的对照（中性提示、长度匹配、更强的验证器、多样本）见 [08_NEW_DIRECTION.md](08_NEW_DIRECTION.md) 第六节。
