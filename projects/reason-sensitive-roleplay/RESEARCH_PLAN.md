## 1. 一句话研究问题

**多轮角色对话中，模型能否依据人物目标和当前证据改变决定，同时不被此前的合作／拒绝姿态带偏？**

该坚持时，不因之前一直配合而让步；该改变时，不因之前已经拒绝而继续固执；信息不足时，指出需要核实什么。以上判断通过自然角色回复体现，不以固定决策JSON、选择题或游戏引擎任务替代自然对话。

研究仍属于 Persona Consistency / Character Fidelity：浅层口吻与实际动机可能脱节，长历史可能影响条件使用。角色主体性不等于机械拒绝，人设一致性不等于永不改变。方向B（信息来源与信念）和C（误解后的选择性修正）只作储备，本次不并行建设完整项目。

## 2. 为什么现在可以开做

用户已放开离线合成数据条件：使用现有 Astra 总控和 Terra 并行配额生产受控故事族，不再限于现成语料的小规模改写。**150族校准与批量覆盖生产并行；2,000族仅是第一版里程碑，随后累计扩展到20,000、50,000族，若新增数据仍有独立信息价值则争取100,000族以上。数据工作不等待GPU实验批准。**

真正要补的是自然单线对白中难以获得的联合结构：同一人物、匹配历史、有效／无效理由、应该保持／改变的关系，以及风格匹配但决定错误的候选。不是只把人物名字和闲聊数量扩到十万条。

强提示／显式条件摘要表现好，说明存在教师脚手架信号，可以内化为部署时不需要额外推导表的策略。它不是停止后训练的理由。SFT、DPO、节点RL是公平参照，不是研究开工的否决门槛。

## 3. 任务与数据单位

输入 `x=(自然人设, 对话历史, 角色可见情境, 玩家发言)`；输出自然台词及可选动作描写。思考格式是可控变量，不强制长独白。评价主要看玩家实际看到的最终回复。

一个 story family 包含两类历史、六类条件、四格候选、角色可见证据、作者契约以及条件图。**故事族／更高层 split_group 是划分和统计单位。** 改名、重写、同一剧情的对立人格与平行分支不能散落训练和测试。

### 六分支覆盖

| 类型 | 要检验什么 |
|---|---|
| B1 日常请求 | 自然帮助，不因拒绝历史而无端防备或复述人设。 |
| B2 无新理由的施压 | 不因合作惯性而放弃当前有效条件。 |
| B3 似是而非的理由 | 分辨理由实质，而非看到长解释就让步。 |
| B4 通用诱因 | 决定取决于人物动机，金钱并非永远应拒绝。 |
| B5 满足人物目标的有效条件 | 有理由地改变决定，克服不当固执。 |
| B6 关键信息不足 | 点名缺失条件，提出可行核验，不把模糊拖延当审慎。 |

这六类不是答案类别。正反人格、条件组合要打破类型与答案的固定对应。全部人物不能都是善良守门人：覆盖利润／信誉、求知／程序、自尊／交易、独立／协作、忠诚／规则、承诺／效率、创作／配合等目标。

### 双历史与四格候选

自然子集保留合作较多和拒绝较多的15–25个问答往返。机制子集先渲染4–6个独立已结事项块，再由Python精确置换顺序；禁止让模型分别重写两段历史。只在相关条件、未结承诺、资源与证据不变时标注决定保持。完整语言分布、情绪和语气不要求相同。

每节点生成正确决定／自然角色表达、正确决定／平实自然表达、错误决定／自然角色表达、错误决定／平实自然表达。平实不自动低质；角色化不是黑话密度。另增决定正确但证据错误、空泛核实、过度表演等校准负例，不能由四格目标标签推断这些维度已得到独立标注。

## 4. 可检验的研究问题与机制假说

**RQ1：何时出现双向历史姿态影响？** 在当前决策条件匹配时比较不当接受、不当拒绝、核实质量及自然度。长短历史、自然与块置换子集分别报告。拒绝可能来自真实新增理由，不能一律称为惯性。

**RQ2：教师条件摘要如何内化？** 相同人物与可见事实下，比较自然输入和结构化推导输入；使用离线正确示范／偏好初始化，或可获取logits的本地教师进行学生轨迹上的蒸馏。用户只有文本型教师输出时不假装拥有全词表概率。

**RQ3：显式条件关系是否改善学习？** 在相同底座、初始化、节点数据与采样预算下，比较拆散节点训练与保持／改变关系训练；关注薄弱条件、样本效率与新人物／新组合，而非只看总体奖励。

机制解释保持开放：条件未理解、条件可读但未落实、历史自模仿、候选覆盖不足、评分器偏好文风都值得检验。不能预写“发现三条正交轴”或“证明RM只看口头禅”。发现哪种解释更有支持，就把方法投入对应环节。

## 5. 主方法路线

1. **教师脚手架内化**：教师给出由学生可见输入推出的生效条件、无效理由和自然回复；学生学习使用人物信息，而不是猜测教师独有的秘密。SFT/DPO初始化与在线蒸馏均可使用。
2. **条件关系训练与分支信用分配**：节点奖励同时要求决定和依据合格，自然度不能补偿决定错误；关系边只有两端合格且满足允许的保持／改变关系才得分。使用固定对称边权和分支级leave-one-out优势，避免把六种prompt混成同一GRPO组。
3. **零信号恢复**：在线池保持纯学生采样。全错／全同分触发诊断和独立教师CE/KL辅助任务；可用明确单列目标的固定正确锚点支持关系比较，但它不能让全错当前节点凭空获得非零RL优势。详细公式、采样条件与消融见METHOD。
4. **本地快评分器**：自然文本先提取决定、依据和核实行为，再计算奖励。四格数据经独立审查后用于多头评分器；补充在线学生输出防域移。32B/70B裁判主要离线标注、抽审和争议仲裁，不默认每步全量调用。

本方案是待实测的方法原型，不保证优于DPO/GRPO。普通DPO能够学习条件偏好；新增关系目标应通过实际数据证明额外收益。没有必要为了保住方法而削弱简单基线，也不因基线有效就退出后训练研究。

## 6. Probe与激活实验

策略模型在首个生成token前读出当前条件满足度、人物目标与近期姿态；同一个确定性前缀不能仅凭后来不同采样结果伪造成不同的生成前状态。跨角色、模板和历史长度验证，再做匹配条件的少量patching。

奖励模型在看完候选后研究决定／依据／文风偏好，与策略的生成前机制分开。数据因素控制不保证表示几何正交。随机方向、长度／文本基线和同预算重锚定是必要对照；Probe本身不强制进入奖励或部署。

## 7. 实验与证据布局

| 对照 | 用途 |
|---|---|
| Base自然输入 vs 同信息教师脚手架 | 区分条件使用和可利用教师信号。 |
| 同训练池SFT / DPO | 测数据本身的增益，提供部署基线。 |
| 节点RLOO `lambda=0` vs 条件图RLOO | 隔离关系目标。 |
| 教师辅助开／关 × 关系开／关 | 不把教师监督增益误归因到图结构。 |
| 均匀边权 vs 对称度数权；固定锚点开／关 | 验证工程补丁与新目标的实际价值。 |
| 独立自然对话、短闭环、公开角色评测 | 检查是否只学会受控模板，及原有能力是否损伤。 |

先用当前可服务的一个7B–14B基座跑通，再按研究需要加入CoSER等角色模型和另一个模型家族；不要求四个模型同时就绪才开始。原有HER/APC/CRPO等接口审查线索见历史交接和资源地图，不必全部复现。

主指标分开报告：不当让步率、不当固执率、B6有效核实率、单节点决定与依据合格率、关系两端同时满足率、人物切换响应、自然度／相关性。给出同族配对差异、角色／故事族级不确定性和代表性失败；不把每候选当独立样本。RoleCDE/RoleMRC/CharacterBench用于相应迁移和能力回归，不自动证明双向惯性已解决。

## 8. 生产规模与执行

Pilot 150族（独立开发用途）；**里程碑按累计规模推进，不设训练集硬上限**：首批 train/dev/test = 2,000/200/300；正式规模20,000/1,000/2,000；大规模扩展50,000/2,000/5,000；有效结构仍不断增加且已有资源允许时，继续争取训练100,000族以上。每族2历史×6分支×4候选；20,000训练族即240,000节点／960,000候选，50,000族即600,000节点／2,400,000候选。上述数字是生产目标而非现有成果，重复样本、失败重试与额外校准切片单独计数。

数据按已审查的版本快照持续交付，训练与Probe无需等待最大规模完成。扩大数量不应靠改名、改职业的同构模板堆积：持续覆盖不同人物目标、世界规则、证据结构、玩家施压方式、合理改变方向与自然语言风格，记录语义近重复、覆盖饱和与独立审查通过情况。测试在生成前按故事来源／模板分组锁定，不能进入教师锚点、评分器训练、Probe拟合或错误驱动扩产；新扩展测试应保持未触碰状态到正式验证。

覆盖流先运行；初始训练配比70%覆盖、30%困难定向，后者没有GPU反馈时可先用预先声明的困难结构，不伪称模型实测难例。机制块置换是既定集合中的子集，不是额外加一套benchmark。

日常4×A100／Pro 6000用于小模型、评分器和Probe；周末8×H20用于在线训练。吞吐和显存以实测决定，不承诺毫秒评分或固定工期。离线生成继续使用现有授权配额；未经授权不新增付费服务。

## 9. 交付标准

第一批交付必须包括真实故事族、隔离输入、原始生成与盲审记录、结构检查、样本状态和覆盖统计，而不仅是设计报告。先打通小批完整链路，再以已校准协议并行扩产；不要求等待150族全部人工审完才准备生产任务。

本地Agent可调整生成模板、采样、分批、局部协议和训练实现，维护简洁变更记录。改研究主干、追加收费或扩大到外部游戏环境仍需用户授权。所有代码测试、大模型实验、质量审查和正式结果分别记账，不互相替代。
