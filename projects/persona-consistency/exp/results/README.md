# 各实验当时的汇总表

这些文件是实验进行时生成的汇总。**其中所有依赖 LLM 裁判的数值，都来自未经人工验证的 Qwen3-32B 非思考裁判（或 Mistral-Small 交叉裁判）**。2026-11-02 的审计表明，该裁判会漏掉大多数“接受错误说法”的回复，所以这些数值只作为历史记录保留，不能作为结论引用。

不依赖 LLM 裁判的表仍可参考：
- `e0a_*` 中的 APC 分量（DeBERTa NLI）；
- `e0g*_minimalpair_*`（线性探针 AUC）。

经验证裁判下的数值见 [../../SUMMARY.md](../../SUMMARY.md)。
