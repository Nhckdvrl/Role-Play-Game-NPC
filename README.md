# Role-Play-Game-NPC

以 **Role-Playing 本身**为核心的语言模型与游戏 NPC 智能体研究地图：人物身份、心理状态、知识边界、角色记忆、玩家—NPC 对话、符合角色动机的行动与世界反馈，以及训练、评测与多模态表达。一般 Minecraft 协作、战斗控制和任务规划仅作为必要的外围背景。
