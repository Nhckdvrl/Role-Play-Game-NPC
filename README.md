# Role-Play-Game-NPC

**以 Role-Playing NPC 本身为核心**的中文研究领域地图：人物身份、性格、动机与情绪，知识与错误信念、记忆与关系、角色成长，以及面对玩家时自然可信的对白与行为。Game 是有世界状态和玩家干预的交互情境；通用多智能体协作、资源采集、战术与低层部署只作必要背景。

## 研究范围

**核心：** 人物设定、心理与内心推理、自然表达、知识边界、人格控制、主观记忆和角色成长、角色训练与评价。

**直接交叉：** 玩家意图与试探、规定情境的角色行为、承诺和世界反馈、图像/语音中的人物表现。

**相邻背景：** 多 NPC 任务协作、游戏操作和工程调度，仅在能解释 Role-Play 时保留。

**核验快照：2026-10-30。** 其中 M 82 篇（研究主文与必要附录阅读）、T 25 篇（定点核读）、B 6 篇（摘要及资源核查）；92 篇发表于或首发于 2025–2026。另有 4 篇官方工程资料，不计入论文数量。看到开源资源不表示已独立训练或复现论文。

**本地图不提供选题推荐、方向优先级或实验排期。** 它是一份可由研究问题追溯到论文、数据、评价协议与 baseline 的案头指南。
