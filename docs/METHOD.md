# 方法 v0.2：条件关系训练、分支信用分配与教师恢复

> 2026-11-01。待实测的方法原型；公式与代码单元测试不等于大模型训练结果。当前实现见[data_factory/family_reward.py](../data_factory/family_reward.py)，评分接口见[EVALUATOR](EVALUATOR.md)。

## 1. 学习对象与增量

节点输入 `x_b` 是一个自然角色对话前缀，输出 `y_b` 是自由台词。族内边描述相关决定应保持或改变的关系，不要求逐token相同。

假说：相同数据、底座、初始化和采样预算下，显式关系监督与分支信用分配有助于薄弱条件、样本效率或跨人物泛化。普通DPO能学习条件偏好；单点RL也可以学到正确决定。新增方法的价值由比较体现，不用“不可能被普通方法学会”作立项依据。

教师脚手架把人物条件推导显式化，学生部署时仍保留足够的自然人设与可见事实。离线文本示范可用于SFT/DPO；token级蒸馏须使用真实能返回概率的本地教师，不假定Astra/Terra提供全词表logits。来源参照OSPD、Intent-OPSD，见[SOURCES](SOURCES_DIRECTION_A.md)。

## 2. 自由文本评分

对每个回复独立调用经校准的语义评分器，缓存：决定类别d、决定合格度c、依据忠实度g、自然度n和B6核验合格度v，均保留来源和置信度。

\[
q_b=c_b g_b v_b,\qquad f_b(y_b)=q_b(1+\eta n_b).
\]

非B6取v=1。B6的v要求点名一条充分核验路线、提出可行检查且不提前承诺。产品q是训练效用的组合，不凭空解释成统计独立事件的精确联合概率。正确性或依据被判为零时，自然度不能补偿。

对有方向的边e=(u,v)：

\[
\kappa_e(y_u,y_v)=q_uq_v\mathbf1[(d_u,d_v)\in\mathcal A_e].
\]

两端都错但决定一致不会得到该关系奖励。保证是相对于评分器给出的q；评分器本身仍可能误判或被策略利用，因此需要独立抽审、在线域数据和冻结的最终评价。

## 3. 度数归一化：先定义一个共同目标

令B为节点数，D_b为节点度数。默认采用对称边权：

\[
w_{uv}=\frac1B\left(\frac1{D_u}+\frac1{D_v}\right),\qquad
F(Y)=\frac1B\sum_b f_b(y_b)+\lambda\sum_{e}w_e\kappa_e.
\]

它等价于对每个节点的“相邻边质量均值”再取节点平均。孤立节点的关系项为零；全部节点非孤立时sum_e w_e=1。作为消融保留uniform模式w_e=1/|E|。

**不能仅在计算节点b的优势时把权重换成1/D_b，却仍声称是原来全局F的无偏梯度。** 同一条边影响两个端点，必须用同一固定权重计算两端贡献。上述目标明确改变了边权，代码和比较均按新目标处理。它减少简单的度数累加效应，但不保证每个节点的梯度方差完全一样；仍记录节点度数、总入射权重与优势分布。

## 4. 成对因子的边缘化与RLOO

每个节点从固定rollout策略独立采样K_b>=2条回复；各节点共享模型参数但随机采样独立。先冻结评分器、输入、图和超参数。

\[
S_{bk}=\frac1B f_b(y_{bk})+
\lambda\sum_{e\in\delta(b)}w_e\frac1{K_v}\sum_j\kappa_e(y_{bk},y_{vj}),
\]

其中边输入顺序遵循source/target，不因当前节点换位而反转允许组合。定义

\[
A_{bk}=S_{bk}-\frac1{K_b-1}\sum_{\ell\ne k}S_{b\ell}.
\]

与b无关的节点／边在条件期望中是常数，基线相减后消失。由联合分布product_b pi(y_b|x_b)的score-function恒等式，梯度为各节点 `grad log pi * (F-baseline)` 的和。同节点其他独立候选及邻居池构成不依赖当前候选的基线，因此在上述冻结、独立采样条件下有合理的无偏起点。每节点对K_b取平均，再对节点**求和**；不要无意再除一次B而改变整体学习率。

参考COMA的反事实信用分配和RLOO，但本实现没有centralized critic。共享参数不妨碍对节点项求和；PPO/GRPO式多epoch clip仍是近似surrogate，不继承无偏单步估计的全部性质。重要性比、KL与长度归一化在训练器中明确记录。

复杂度为O(sum_e K_u*K_v)次缓存标量计算；每条自然回复只需一次语义评分，不需要枚举K^B个族或为每条边调用大裁判。两历史×六分支×K=4为48条rollout，可以分批生成，必须保留同一policy_version。计算复杂度下降不等于整体RL已达到某毫秒吞吐。

## 5. 全错／零方差处理：不伪造on-policy样本

当一个节点所有候选q=0时，节点与乘性关系项都为零，RLOO优势也为零；邻居全错会使对应在线边暂时无信号。全同非零分也可能没有优势。这是有限采样下的零信号，不是证明原始期望目标永远没有梯度。

### 默认恢复路线

1. 用经审查的正确示范／偏好作warm-start。
2. 记录all_fail、quality_tied、实际advantage_std、有效候选数和评分器置信度，区分无好候选与评分故障。
3. 对训练侧困难节点建立**独立**教师CE或可用的教师KL辅助任务。示范用来源明确的正确回复；不把示范替换进在线K条里，不伪造其old_log_prob。
4. 对该节点在后续policy版本重新采样；可在固定预算下增加K或调整温度，记录预算，不承诺必有好样本。

总损失可以写为 `L = L_policy(F) + beta_aux L_teacher + beta_KL L_reference`。辅助CE按回复token长度归一化。当前批失败门控属于自适应的辅助训练选择，不把它冒充原始RL目标的无偏梯度。新旧方法的辅助监督预算需匹配，或单独消融。

### 可选：固定正确锚点支持关系，而非替换在线池

对每节点保留训练侧、独立审查通过的固定锚点池a_b，定义明确的新目标：

\[
\kappa_e^\alpha=(1-\alpha)\kappa_e(y_u,y_v)+
\frac\alpha2\{\mathbb E_{a_v}\kappa_e(y_u,a_v)+\mathbb E_{a_u}\kappa_e(a_u,y_v)\}.
\]

将F中的kappa替换为该式。alpha与锚点在本批采样前固定；如需按失败率调整，用上一批统计。默认alpha=0保留纯在线关系基线；小的正alpha是待测设置。

计算S_bk时，在线邻居均值项乘(1-alpha)，另加当前候选与固定邻居锚点的alpha/2项；仅含当前节点固定锚点而不含当前在线候选的项是常数，消失。代码的score_family和conditional_scores使用同一个目标。

这能在邻居全错但当前节点有好候选时保留部分关系信号；**当前节点自身全错且q=0时仍不能凭空制造优势**，须依靠独立教师辅助。不能写“注入一个老师答案就保证所有关系梯度畅通”。强行替换在线采样会改变行为分布；本版不采用该实现。

## 6. 训练器与评分器接口

每条rollout至少存 `family_id,node_id,sample_id,policy_version,prompt_hash,response,old_log_prob`。评分缓存键包含完整输入hash、回复hash、评分器／rubric版本。解析错误、超时、拒评进入重试或隔离，不写成角色质量零分。

同一更新使用冻结评分器。本地评分器训练时也不能读取test，不能将设计标签直接冒充独立判断。评分快慢路由的标准和覆盖率固定并记录。实测包含长prompt prefill、序列化、排队、显存、评分batch与端到端step时间；不能仅测核函数推断整个环节为毫秒。

若默认每族总奖励尺度随节点数改变，按目标和batch聚合检查学习率。不要把不同prompt的分数混成单prompt GRPO组，不要把语义决定类别的概率当作某个“拒绝”token的概率。独立同分支候选是LOO基线的基础。

## 7. 最小有效比较与Probe

主比较是teacher_aux开／关 × relation开／关，保持初始化、节点数据、采样和评审预算接近；再比较uniform/degree和alpha锚点。SFT/DPO、节点RLOO和教师蒸馏各保留有意义的参照，不必先复现全领域。

Probe分为生成前策略状态和候选后评分器状态。前者检验条件、人物目标、近期姿态的可读性及后续行为；后者检验文风是否影响正确性判断。跨角色／模板split、匹配长度与准确token位置，生成后文本信息不能称为生成前预警。三种标签不等于三条已发现的正交轴。

## 8. 实现状态

仓库提供目标评分、对称度数边权、可选固定锚点目标、分解条件分数、LOO优势与恢复诊断接口，并附玩具分布上的有限差分／穷举测试。它不是完整veRL trainer，不含已训练评分器、教师服务或大模型实测结果。本地agent以这些接口连接现有训练栈；数据生产无需等待这些GPU组件完成。
